# Trifacta

> Trifacta is a data wrangling and data preparation platform for collaboratively profiling, structuring, cleaning, enriching, and pipelining data for analytics and machine learning. Acquired by Alteryx in 2022, it is now Designer Cloud powered by Trifacta and underpins Google Cloud Dataprep. Trifacta exposes a versioned REST API across its editions and ships a first-party Python SDK.

## API
- [Trifacta REST API reference](https://api.trifacta.com/): Endpoint reference for flows, recipes, datasets, jobs (jobGroups), and connections across all product editions.
- [Designer Cloud SaaS API reference](https://api.trifacta.com/saas-enterprise-cloud22/index.html): REST reference for the Designer Cloud SaaS edition.
- [Enterprise (Self-Managed) API reference](https://api.trifacta.com/ee/9.7/index.html): REST reference for the self-managed Enterprise v9.7 edition.
- [Google Cloud Dataprep API reference](https://api.trifacta.com/dataprep-enterprise-cloud22/index.html): REST reference for the Google Cloud Dataprep edition.
